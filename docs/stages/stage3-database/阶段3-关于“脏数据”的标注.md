明确。在前端 Store 引入“脏数据标记（Dirty Flag）”与“视觉阻断”机制，能够从底层切断输入参数与陈旧计算结果在空间层（3D 视图）与数据层（右侧面板）的错误映射。

以下是前端状态机与 UI 层的最小化修改方案：

### 约束条件—实现方式—影响范围 评估

* **约束条件**：用户加载包含历史结果的快照后，只要对任意 38/41 个参数进行了哪怕 1 毫米的滑动修改，系统必须立即判定当前 UI 展现的“安全系数、间距孔径”已失效。
* **实现方式**：在 Pinia 中增加 `isDirty` 标识拦截器；在 UI 结果面板增加条件渲染遮罩（Mask）。
* **影响范围**：仅修改前端状态管理库与结果视图的响应式逻辑，不影响 3D 底层计算引擎。

### 修改位置一：数据状态机拦截配置

**目标文件**：`frontend/src/store/parameterStore.ts`

**修改内容**：

1. 在 State 中新增脏数据标记 `isDirty` 与结果容器 `currentResults`。
2. 在 Actions 中劫持参数更新与数据加载逻辑。

```typescript
// frontend/src/store/parameterStore.ts
import { defineStore } from 'pinia'

export const useParameterStore = defineStore('parameter', {
  state: () => ({
    // ... 原有的 38/41 个入参定义 ...
    
    // [新增] 状态标记与结果缓存
    isDirty: false,          // 脏数据标记：默认为 false
    currentResults: null as any | null, // 存放后端返回的计算结果 (安全系数、间距等)
  }),

  actions: {
    // 1. [拦截器] 单一参数修改动作
    updateParam(key: string, value: any) {
      this.$state[key] = value
      // 只要发生人为修改，立即标记为脏数据，并主动销毁旧结果
      if (!this.isDirty) {
        this.isDirty = true
        this.currentResults = null 
      }
    },

    // 2. [拦截器] 接收后端最新计算结果
    setCalculatedResults(results: any) {
      this.currentResults = results
      // 获得新结果，清除脏标记
      this.isDirty = false 
    },

    // 3. [拦截器] 从数据库或历史列表加载快照
    loadSnapshot(snapshotData: any) {
      // 覆写全量输入参数
      this.overrideAll(snapshotData.parameters_json)
      // 同步恢复当时的历史计算结果（若存在）
      this.currentResults = snapshotData.results_json || null
      // 初始加载状态视为干净数据
      this.isDirty = false 
    }
  }
})

```

### 修改位置二：右侧结果面板的视觉阻断

**目标文件**：`frontend/src/views/Dashboard.vue`（或具体的右侧结果卡片组件）

**修改内容**：
绑定 `parameterStore.isDirty` 状态。当状态为 `true` 时，激活 CSS 滤镜（高斯模糊与透明度衰减）冻结底层图表，并在顶层弹出警告横幅，阻止用户读取陈旧数据。

```html
<!-- frontend/src/views/Dashboard.vue (右侧结果面板区域截取) -->
<template>
  <div class="result-panel-container" style="position: relative;">
    
    <!-- [新增] 脏数据拦截遮罩层 -->
    <div v-if="parameterStore.isDirty" class="dirty-data-mask">
      <el-alert 
        title="输入参数已变更，当前结果已失效" 
        description="请点击工作台顶部的【开始计算】获取最新结果"
        type="warning" 
        show-icon 
        :closable="false" 
      />
    </div>

    <!-- 原有结果展示区：通过动态 class 增加视觉失效反馈 -->
    <div class="result-charts" :class="{ 'is-blurred': parameterStore.isDirty }">
      <!-- 原有的 3D 模型安全系数统计图、管网排布间距卡片等 -->
      <div v-if="parameterStore.currentResults">
         <p>临界水头: {{ parameterStore.currentResults.critical_head }} m</p>
         <!-- ... -->
      </div>
    </div>
    
  </div>
</template>

<style scoped>

  pointer-events: none; /* 彻底禁用图表交互（如 Hover 提示） */
  opacity: 0.5;
  transition: all 0.3s ease;
}

/* [新增] 遮罩层绝对定位居中 */
.dirty-data-mask {
  position: absolute;

</style>
```

**同理联动**：在 3D 渲染核心组件 `Viewer3D.vue` 中，可同步监听 `parameterStore.isDirty`，若为 `true`，可将 3D 画布右上角的“安全系数仪表盘”变灰或直接隐藏，确保数据表现的全局强一致性。
