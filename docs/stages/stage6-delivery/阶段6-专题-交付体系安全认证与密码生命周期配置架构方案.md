### 1.2 系统量化指标

- **CI/CD 构建零阻塞率**：GitHub Actions 云端全自动构建因密码配置缺失或交互中断的发生率严格控制为 $0\%$；
- **桌面端密码固化可靠性**：桌面客户端打包产物在脱离源码及未挂载外部 `.env` 时，出厂内置密码识别准确率 $100\%$；
- **构建敏感文件入 Git 泄露率**：在本地执行手动编译或测试打包时，构建临时文件、密钥及配置提交到 Git 仓库的概率为严格 $0\%$；
- **临时密码构建文件残留率**：构建脚本异常中断或崩溃退出时，临时密码生成文件的磁盘残留率为 $0\%$（基于 `try ... finally` 物理回收保证）；
- **服务器改密生效时延**：环境变量修改后通过 `docker compose restart backend` 容器热重启生效时延 $\le 15\,\text{s}$；
- **架构极简度与攻击面收敛**：去除在线改密端点后，减少后端 API 1 个、减少持久化表 1 张、减少前端改密弹窗 1 个，系统代码复杂度下降约 $40\%$；
- **UI & Typography 生理底线**：一次性认证弹窗 [AuthDialog.vue](file:///d:/offices/Github/隧道工程多维协同智能排水自适应平台/tunnel-drainage-platform/frontend/src/components/ui/AuthDialog.vue) 及状态反馈提示字体严格满足 $\text{font-size} \ge 12\text{px}$。

## 二、 Constraints & Boundary Contract Matrix (约束条件与边界契约矩阵)

### 2.1 事实、判断与推测分离准则 (Fact, Judgment and Speculation)

- **事实 (Fact)**：
  - 代码库当前 [backend/app/core/config.py](file:///d:/offices/Github/隧道工程多维协同智能排水自适应平台/tunnel-drainage-platform/backend/app/core/config.py) 通过 `os.getenv("PLATFORM_AUTH_PASSWORD", "chongqing123456")` 读取口令，属于环境变量单点。
  - [backend/app/services/auth_service.py](file:///d:/offices/Github/隧道工程多维协同智能排水自适应平台/tunnel-drainage-platform/backend/app/services/auth_service.py) 实现了基于 HMAC-SHA256 的会话令牌签名和常量时间比对（`verify_operator_password`），并内置了 `InMemoryRateLimiter` 滑动窗口限流防爆破机制。
  - 当前 [backend/app/api/v1/endpoints/auth.py](file:///d:/offices/Github/隧道工程多维协同智能排水自适应平台/tunnel-drainage-platform/backend/app/api/v1/endpoints/auth.py) 仅开放了 `GET /status` 与 `POST /verify` 接口，无在线改密端点。
  - 根目录 [.gitignore](file:///d:/offices/Github/隧道工程多维协同智能排水自适应平台/.gitignore) 当前未对 `.env`、`.env.production` 或编译期动态注入配置文件进行全面排除。
  - 桌面独立端基于 Tauri 2.0，后端采用 PyInstaller 打包为 `tunnel-backend-sidecar.exe`；服务器端通过 Docker Compose 编排。
- **判断 (Judgment)**：
  - 工业控制与计算软件的在线修改密码属于高成本、低收益的非必要功能。移除 Web 端在线改密，坚持 Docker 容器标准的 12-Factor 运维配置规范（修改 `.env` 重启生效），能完全消灭“环境变量 vs 数据库持久化哈希”的优先级冲突和配置漂移反模式。
  - 桌面独立端运行在野外施工现场，出厂固化口令并统一执行敏感操作防护，不设免密旁路，彻底消除现场非授权人员误触修改或破坏工程基准参数的隐患。
  - 本地手动编译可能接触到客户专属密码与定制密钥，若不建立严格的 Git 忽略规则和脚本级清理断言，极易发生敏感配置误提入库的安全事故。
- **推测 (Speculation)**：
  - 私有化部署运维人员更习惯通过自动化运维工具（Ansible、Terraform、Portainer）集中分发 `.env` 配置文件，而非登录 Web 前端逐个节点点击修改。

## 四、 Local Build Security & Git Isolation (本地编译安全屏障与 Git 隔离规范)

### 4.1 严禁提交 Git 的文件黑名单 (Git Prohibited Files Whitelist)

在本地进行手动编译与发布时，必须严格保证以下五大类文件绝对不得进入 Git 版本控制：

| 类别 | 目标文件/路径模式 | 泄露风险等级 | 存在阶段 | 为什么严禁入 Git？ |
| :--- | :--- | :---: | :---: | :--- |
| **1. 临时构建配置** | `**/backend/app/core/_build_constants.py`<br>`**/_build_*.py` | **极高 (Critical)** | 编译中瞬态 | 包含本地编译脚本动态写入的私有化定制明文密码，一旦入库将直接公开给所有代码阅读者。 |
| **2. 生产环境配置** | `.env`<br>`.env.local`<br>`.env.production`<br>`deploy/server/.env.production` | **极高 (Critical)** | 部署运维态 | 包含生产部署口令 `PLATFORM_AUTH_PASSWORD`、签名密钥 `PLATFORM_SECRET_KEY` 及数据库真实路径。 |
| **3. 数字签名与私钥** | `*.pfx`<br>`*.key`<br>`*.pem`<br>`*.keystore`<br>`*.cer` | **极高 (Critical)** | 客户端打包 | 桌面端 Windows Authenticode 代码签名证书与私钥，一旦泄露可能被恶意利用伪造软件签名。 |
| **4. 本地运行时数据** | `*.db`<br>`*.sqlite`<br>`tunnel_params.db`<br>`tunnel-drainage-platform/backend/data/*.db` | **中高 (High)** | 本地调试/测试 | 包含开发与测试期间写入的真实隧道工程断面、实测水质、排水量等涉密工程参数。 |
| **5. 最终交付物料** | `src-tauri/binaries/tunnel-backend-sidecar.exe`<br>`dist-desktop/`<br>`dist-docker/`<br>`*.msi`<br>`*.exe` | **中度 (Medium)** | 编译产物 | 属于大尺寸二进制产物，会迅速膨胀 Git 仓库体积，且二进制逆向可能暴露私有构建特征。 |

### 4.3 构建脚本物理清理保证机制 (Trap / Finally Guarantee)

为了防止手动编译过程中因用户强行按 `Ctrl+C` 中断或 PyInstaller 编译报错导致 `_build_constants.py` 残留在工作区，PowerShell 构建脚本必须实施**确定性回收闭环**：

```powershell
# deploy/scripts/build-desktop.ps1 片段

$BuildConstantsPath = Join-Path $PSScriptRoot "../../tunnel-drainage-platform/backend/app/core/_build_constants.py"

try {
    # 1. 动态生成临时固化口令文件
    Write-Host "[Security] 正在生成临时构建固化配置文件..." -ForegroundColor Cyan
    $configContent = @"
# AUTOMATICALLY GENERATED BY BUILD SCRIPT. DO NOT COMMIT TO GIT.
BUILTIN_AUTH_PASSWORD = "$OperatorPassword"
BUILTIN_AUTH_MODE = "desktop"
"@
    Set-Content -Path $BuildConstantsPath -Value $configContent -Encoding UTF8 -Force

    # 2. 触发 PyInstaller 冻结打包
    Write-Host "[Build] 正在打包桌面端 Sidecar 二进制..." -ForegroundColor Green
    # 执行打包命令...
}
finally {
    # 3. 终局清理：无论成功、失败或中断，必须物理删除临时文件
    if (Test-Path $BuildConstantsPath) {
        Remove-Item -Path $BuildConstantsPath -Force -ErrorAction SilentlyContinue
        Write-Host "[Security] 临时构建文件已安全擦除，Git 工作区已恢复洁净。" -ForegroundColor Green
    }
}
```

### 4.4 Git 洁净度前置断言门禁 (Pre-build Git Sanity Gate)

在运行构建脚本前，自动化脚本将执行 Git 状态预检，若检测到工作区存在未跟踪的敏感文件或未配置忽略规则，脚本直接退出并报错阻断：

```powershell
# deploy/scripts/build-desktop.ps1 前置断言

$gitStatus = git status --porcelain 2>$null
if ($gitStatus -match "_build_constants\.py|\.env\.production") {
    Write-Error "[Security Gate] 检测到工作区存在敏感配置文件未被完全忽略或已被暂存，构建已被物理阻断！"
    exit 1
}
```

## 五、 Detailed Design & Engineering Specifications (详细设计与接口契约)

### 5.1 桌面端密码真固化机制 (True Binary Constant Baking)

为了确保桌面客户端在用户脱机环境下不依赖任何外部环境变量或 `.env` 文件，系统采用“编译时常量动态重载”模式：

```
+───────────────────────────────────────────────────────────────────────────────────────+
|                           桌面端密码真固化装配生命周期                                |
+───────────────────────────────────────────────────────────────────────────────────────+
  [本地源码仓库]                               [编译瞬态]                         [输出产物]
  backend/app/core/config.py              _build_constants.py           tunnel-backend-sidecar.exe
       │                                       │                                   │
       ├─ try import BUILTIN_AUTH_PASSWORD ───>│ (由打包脚本注入定制密码)                  │
       │                                       │                                   │
```

```powershell
# deploy/scripts/build-desktop.ps1
param (
    [string]$OperatorPassword = "",
    [switch]$NonInteractive = $false
)

$ErrorActionPreference = "Stop"
$PSScriptRoot = Split-Path -Parent $MyInvocation.MyCommand.Definition
$ConstantsFile = Join-Path $PSScriptRoot "../../tunnel-drainage-platform/backend/app/core/_build_constants.py"

# 1. 交互式获取口令
if (-not $OperatorPassword -and -not $NonInteractive) {
    Write-Host "======================================================" -ForegroundColor Cyan
    Write-Host "  [安全配置] 隧道工程平台桌面独立客户端 - 操作口令固化配置" -ForegroundColor Cyan
    Write-Host "======================================================" -ForegroundColor Cyan
    $inputPwd = Read-Host "请输入出厂固化操作口令 (直接回车使用默认: chongqing123456)"
    if ($inputPwd.Trim()) {
        $OperatorPassword = $inputPwd.Trim()
    } else {
        $OperatorPassword = "chongqing123456"
    }
} elseif (-not $OperatorPassword) {
    $OperatorPassword = "chongqing123456"
}

# 2. 安全构建生命周期闭环
try {
    # 动态写入临时常量 (受 .gitignore 严密保护)
    $content = @"
# AUTOMATICALLY GENERATED. DO NOT COMMIT TO GIT.
BUILTIN_AUTH_PASSWORD = "$OperatorPassword"
BUILTIN_AUTH_MODE = "desktop"
"@
    Set-Content -Path $ConstantsFile -Value $content -Encoding UTF8 -Force
    Write-Host "[Build] 已注入固化口令，正在调用 PyInstaller 冻结 Sidecar..." -ForegroundColor Green

    # 执行 PyInstaller 打包流程...
    # pyinstaller tunnel-drainage-platform/backend/packaging/sidecar.spec
}
finally {
    # 无论成功或失败，强制物理清除
    if (Test-Path $ConstantsFile) {
        Remove-Item -Path $ConstantsFile -Force -ErrorAction SilentlyContinue
        Write-Host "[Security] 临时编译常量已物理销毁，Git 工作区无任何文件残留。" -ForegroundColor Green
    }
}
```
