# 【阶段6-实施方案】：地下水主动控制系统 3 分钟特效宣传与施工指导视频实施方案 (轻量高效落地版)

> **系统分析师声明 (System Analyst Mandate)**：  
> 本方案严格依据“地下水主动控制系统”（区段隔离 · 出口受控 · 监测反馈调节）工程切面与侧墙检修洞室放大图，结合当前“隧道工程多维协同智能排水自适应平台”已建成的软硬件闭环体系，制定一份**集广告宣传震撼视觉与一线施工运维精准指导于一体的 3 分钟（180 秒）特效视频实施方案**。  
> 经 `/verifier` 两轮白盒深度核查，本方案全面剔除“重型 MCP 跨进程总线编排”与“全链路扩散模型反复抽卡”的过度工程化陷阱，**确立“战略级解耦分工（帕累托最优）”**：宏观风光与痛点引子由 AI 视频模型直出震撼大片（极速省时），微观管网与机电控制由 Blender 参数化与 BIM 流光着色器确定性呈现（零工程幻觉），配音采用零成本秒级合成（`edge-tts`），全片工时从 40+ 小时压缩至 **8~12 人工时（1~2 个工作日定稿交付）**，兼具国家级工业汇报的高级质感与现场技术交底的严苛规范性。

## 一、 Objectives (目标体系与受众契约)

### 1.1 核心交付指标
1. **时间规格**：全长严格控制在 **3 分钟（180 秒 ± 2 秒）**，快慢相宜，信息流密度符合现代工业微纪录片节奏。
2. **分辨率与帧率规格（分层轻量渲染）**：
   - **生产与剪辑基线**：**1080P (1920×1080) @ 60fps**（保障水流粒子流动丝滑，避免 4K 全流程 10,800 帧导致的显存与磁盘 I/O 拥塞）；
   - **交付母版规格**：经后期 AI 超分增强（Topaz Video AI / Real-ESRGAN）一键升频为 **4K UHD (3840×2160) @ 60fps**，下发网络/移动端分发版为 **1080P @ 60fps**。
3. **音频规范**：
   - 工业科技解说男声（采样率 $48\,\text{kHz}$，位深 $24\,\text{bit}$），整体响度符合广电级标准（Integrated Loudness: $-14\,\text{LUFS} \pm 1\,\text{LU}$）；
   - **有效口播净时码与字数硬约束**：扣除片头沉浸式无声/音效留白（5s）与片尾品牌定格（10s），有效解说净时长为 **165 秒**；按照工业科技解说标准语速（$220 \sim 240$ 字/分钟），**全片旁白解说词严格锁定在 $630 \sim 680$ 字**，杜绝口播抢拍与时钟漂移；
   - 配套生成毫秒级时间戳外挂与内嵌中文字幕（标配工程专有名词核准）。
4. **软硬一体化双轨叙事**：
   - **硬件真实映射**：完整展示初期支护、防水层、二次衬砌、环向管、纵向管、横向管、中心主水沟、侧墙预留检修洞室（双向流量计、电动V型调节球阀、蝶形截断阀）、电气控制柜及隐蔽应力/变形传感器。
   - **软件中枢驱动**：深度联动本项目 Vue 3.5 前端（参数填报、3D 数字孪生、实时安全系数反演曲线与阈值报警），采用高保真**画中画（Picture-in-Picture, PIP）**体现“数据感知 $\to$ 智能运算 $\to$ 阀组反馈调节”闭环。

### 1.2 广告宣传与施工指导的剪刀差平衡模型
- **矛盾点**：广告宣传要求宏观、宏大叙事、动态粒子、快节奏视觉冲击；施工指导要求微观、构件尺寸、装配间隙、接线逻辑、安装工法与应急检修实操细节。
- **解法（多尺度镜头嵌套与画中画协同）**：
  - **主画面 (Main Canvas)**：承载宏观穿透透视、三维空间切面、全流域水流动态与高冲击力视觉特效（满足宣传与汇报诉求）。
  - **画中画与引线层 (PIP & Callout Overlays)**：在关键工艺节点（如预留检修洞室内部、初支与二衬之间、电控柜箱体），同步弹出微观工程装配大样、实操动作分解动画及施工质量控制红线（满足施工与检修指导诉求）。

## 二、 Constraints & Boundary Contract Matrix (约束条件与成本优化契约)

### 2.1 事实、判断与推测分离准则 (Fact, Judgment and Speculation)

- **事实 (Fact)**：
  - 附图明确定义了空间物理排布：环向盲管沿拱部收集渗水，汇入侧墙底部的纵向排水管；纵向排水管接入检修洞室内；洞室内由前至后安装“双向流量计”与“电动V型球阀”，再通过横向排水管排入中心水沟。
  - 侧墙设预留检修洞室（带花纹钢盖板），且电控柜挂墙布置，有线连接控制阀门。
  - 隐蔽工程（应力计、变形传感器、环向管、防水板）浇筑于二衬背后，完工后不可逆；检修洞室构件属于露明可维护件。
  - 本地拥有单卡 RTX 4090 (24GB VRAM) 与 Gemini Pro API 权限。
- **判断 (Judgment)**：
  - **避免过度工程化（Anti-Over-Engineering）**：本任务为单次高质工业交付物，严禁开发复杂的跨进程 Agent/MCP 自动化编排总线（如专门开发 Blender MCP、obs-websocket 驱动服务、pyJianYingDraft 代码注入）。采用“轻量 Python 脚本 + 交互式非编”可节省 60% 无效脚手架研发耗时。
  - **战略级解耦分工（Pareto Division）**：
    1. **AI 视频模型优势区（极速直出）**：宏观自然风光、大场景穿越与意象痛点（Scene 1 与 Scene 5），直接由 Sora / 可灵 / Wan2.1 文生视频直出好莱坞级航拍镜头，**零 3D 建模成本，1 小时出片**。
    2. **Blender 确定性优势区（零工程幻觉）**：精细管网拓扑、机电装配与工法细节（Scene 2、Scene 3 与 Scene 4），采用 **Blender 参数化脚本 + 现成通用阀门资产 + BIM 科技风（X-Ray 半透明、PBR UV 滚动流水材质）**，单帧渲染耗时 $<0.2$ 秒，杜绝 AI 视频导致的法兰溶解、水流倒灌与螺栓畸变。
  - **语音与字幕零成本化**：剔除本地部署 CosyVoice 大模型的环境配置与显存开销，采用开源命令行 `edge-tts`（指定 `zh-CN-YunxiNeural` 科技男声），秒级直出广播级音频与毫秒级 `.srt` 字幕。
  - **录屏极简化**：直接在本地 Chrome 全屏运行 Vue 3.5 前端，使用系统自带或 OBS 快捷录屏录制 4K/60fps 交互实景，省去 WebSocket 通讯脚本调试。
- **推测 (Speculation)**：
  - 一线施工人员对密闭空间检修、手动/自动模式切换存在操作恐惧，视频必须通过高亮强调“应急手动机械离合摇柄”和“就地手动按钮”，作为防灾培训核心。

## 六、 Verification Plan & Acceptance Criteria (质量门禁与验收基准)

通过轻量化流程产出的成片，必须无条件通过以下两道刚性门禁：

### 6.1 第一道门禁：工程零误差刚性门禁 (Engineering Zero-Defect Gate)
- [ ] **拓扑真实性**：环向管 $\to$ 纵向管 $\to$ 检修室（双向流量计处于球阀上游） $\to$ 横向管 $\to$ 中心水沟，流向无逆流、无断头管路。
- [ ] **构件完备性**：检修室内双向流量计（蓝色）、电动V型调节球阀（橙色执行器）、蝶形阀及盖板法兰螺栓清晰可见，100% 结构保真，无 AI 溶解变形。
- [ ] **隐蔽关系正确性**：应力传感器必须嵌于初支与二衬之间，严禁画在二衬内表面；防水层必须位于初支与二衬之间。
- [ ] **文字无 AI 乱码**：主画面背景视频干净无杂质文字；所有构件引线与说明文字 100% 为后期矢量文字层，字字严格对齐附图技术名称。

### 6.2 第二道门禁：视听舒适度与交付门禁 (Audiovisual & Delivery Gate)
- [ ] **字号生理底线**：在 1080P 参考视口下，所有引线标注与提示文字高度 $\ge 12\text{px}$（4K 母版下 $\ge 24\text{px}$），行距清晰，防眩光描边。
- [ ] **声画同步精度**：解说词提到构件名称瞬间，对应发光引线在 $\pm 100\,\text{ms}$ 内点亮并平滑伸展；提到工况切换瞬间，画中画内前端图表曲线同步跳变。
- [ ] **音频响度合规**：全片音频一体化响度为 $-14\,\text{LUFS} \pm 1\,\text{LU}$，无爆音，人声清脆饱满，背景音乐（BGM）与机械音效（SFX）不掩盖人声（人声与 BGM 响度差 $\ge 12\,\text{dB}$）。
- [ ] **导出编码合规**：H.264 / H.265 (HEVC), 4K UHD (3840×2160), 60fps, 码率 $\ge 50\,\text{Mbps}$，音频 AAC $320\,\text{kbps}$。
