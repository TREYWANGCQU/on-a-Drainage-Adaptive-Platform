## 一、 问题根因剖析与对齐目标

### 1.1 横向管推荐管径在 3D Viewer 中显示为 80mm 的根因
* **计算引擎能力**：后端计算引擎（`hydrocalc.py` 及 `drainage_engine.py`）在 `drain_design` 方法中基于曼宁公式计算横向管过流能力，并正确输出了 `lateral_diam_recommend`（标准工况下为 0.08m，即 80mm）。
* **前端数据提取缺陷**：前端 `DrainagePipeGenerator.ts` 在 `updateFromSnapshot()` 中提取参数时，环向管正确读取了计算结果 `state.ring_diam_recommend`，但横向管（`latDiam`）和纵向管（`longDiam`）被错误地死锁在表单输入默认值 `params.d_lat_default`，未优先读取引擎返回的 `lateral_diam_recommend`。这导致即便在大涌水量工况下引擎算得推荐管径升级（如 100mm），3D 图层标注仍显示为 80mm。

### 1.2 径向排水管参数来源与处理
* **计算引擎现状**：后端计算引擎目前仅针对环向盲管、纵向排水管与横向连接管建立力学及水力学求解模型，**不存在径向排水管的计算逻辑**。
* **3D 图层问题**：`DrainagePipeGenerator.ts` 中标注的 `径向排水管: L=4.0m Φ50mm` 为纯前端硬编码预设，易使用户误解为计算引擎导出结果。
* **对齐策略**：彻底移除【径向排水管】的 3D 文本标注浮窗，保留 3D 网格实体渲染，消除非引擎计算驱动参数的悬浮干扰。

### 1.3 原始状态与临界状态标注区分与降级
* **状态区分**：在 3D 视窗标注中显式区分 `[原始状态]` 与 `[临界状态]`。
* **空值降级**：当初始安全系数 $K \ge 2.0$（即无需注浆加固，`critical_state` 为空/未生成）时，临界状态视图自动降级复用原始状态管径数据，并友好提示 `[临界状态: 安全储备足够无需注浆]`，防止运行时出现 JS/TS 空指针报错。

## 二、 详细设计与代码修改方案

### 2.1 DrainagePipeGenerator.ts 重构方案

1. **方法签名更新**：
   ```typescript
   public updateFromSnapshot(snapshot: any, viewMode: 'original' | 'critical' | 'all' = 'original'): void
   ```
2. **状态数据萃取与空值降级**：
   ```typescript
   let targetState = snapshot.original_state ?? snapshot.results?.original_state ?? {};
   let isCriticalEmpty = false;

   if (viewMode === 'critical') {
     const critState = snapshot.critical_state ?? snapshot.results?.critical_state;
     if (critState && Object.keys(critState).length > 0) {
       targetState = critState;
     } else {
       isCriticalEmpty = true;
     }
   }
   ```
3. **管径参数精准读取**：
   ```typescript
   this.config.ringDiam = targetState.ring_diam_recommend ?? targetState.d_ring ?? params.d_ring_default ?? this.config.ringDiam;
   this.config.longDiam = targetState.long_diam_recommend ?? targetState.d_long ?? params.d_long_default ?? this.config.longDiam;
   this.config.latDiam = targetState.lateral_diam_recommend ?? targetState.d_lat ?? params.d_lat_default ?? this.config.latDiam;
   ```
4. **标注生成与径向管标注清理**：
   - 环向管：`[状态前缀] 环向盲管: Φxxmm @ X.Xm`
   - 纵向管：`[状态前缀] 纵向排水管: Φxxmm`
   - 横向管：`[状态前缀] 横向排水管: Φxxmm`
   - 彻底删除径向排水管 `createTextSprite` 的创建与挂载代码。

### 2.2 Viewer3D.vue 透传方案

在 `renderSceneData()` 方法中，将组件 Props 中的 `props.mode` 显式透传至 `pipeGen.updateFromSnapshot(rawData, props.mode)`，并确保 `props.mode` 变更时重新执行渲染。

## 三、 验收标准与验证结果

1. **状态区分与空值降级**：
   - 原始状态视图显示 `[原始]` 前缀标注及对应管径。
   - 临界状态视图在 `critical_state` 存在时显示 `[临界]` 前缀标注；在 `critical_state` 为空时无异常报错，提示 `[临界: 安全储备足够无需注浆]`。
2. **径向管标注清理**：
   - 3D 视图场景中不再出现 `径向排水管: L=4.0m Φ50mm` 浮窗。
3. **横向管推荐管径对齐**：
   - 横向管标注管径正确读取引擎推荐值 `lateral_diam_recommend`。
